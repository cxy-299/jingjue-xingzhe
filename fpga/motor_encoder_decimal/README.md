# 数码管测速实验（暂缓上板）

本目录的 74HC595 数据线来自开发板资料给出的 M18，ModelSim 数码管帧与十进制测速仿真均通过。但针对实际 GW5AT-60B 的 Gowin V1.9.12.04 布局布线报错：`PR2017: seg_ds_o ... dedicated pin (SSPI)`，因此**没有生成可下载的有效位流，严禁用此目录进行上板测试**。板卡通用引脚表列有 M18，但该编译器/器件组合不允许当前用法；不能凭 138K 示例直接外推到 60B。

为避免继续试错专用配置脚，测速输出已改走经当前器件布局布线验证的板载 UART TX=M15，见 `../motor_encoder_uart/README.md`。本目录的十进制计数计算模块仍作为串口版本的内部子模块复用；未连接的数码管扫描器由综合器移除。
