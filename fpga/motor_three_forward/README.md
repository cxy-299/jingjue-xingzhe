# M2～M4 前进方向复核（M3FW）

本版仅用于**四轮离地**标定，不是四路闭环位流，也不能落地行驶。根据用户对车轮最下缘运动方向的最终确认：M2、M4 在原接法下已朝车尾运动（车体前进），M3 在原接法下朝车头运动（车体后退）。所以本位流**仅反转 M3** 的方向输入；每按一次 S1 按 M2→M3→M4 顺序，单轮起动 100 ms 全占空比、随后 80% PWM，700 ms 自动停止。S0 急停。

期望的离地现象：三轮每次仅选中一轮，轮子最下缘都朝车尾；M2/M4 的原始编码器计数应仍约为负，M3 的原始计数应由负变正。所有轮的实际方向必须以肉眼观察为准，**不能只凭符号认定前进**。串口 115200、8N1，格式 `M2:-024`、`M3:+011`、`M4:-028`。

ModelSim 2020.4：`PASS tb_acg720_motor_three_forward`，0 errors、0 warnings，检查了仅 M3 反向、轮号隔离、700 ms 超时和 S0 急停；原标定版回归仿真也通过。Gowin V1.9.12.04：50 MHz 约束下 Actual Fmax **104.182 MHz**，建立/保持违例端点均为 0。位流 `impl/pnr/acg720_motor_three_forward.fs`，User Code `0x4D334657`（M3FW），SHA-256 `C0AD5D77DE176E3AF203F52613BC6FDD944B332A242EC2C8317EDCDFB4CE65D5`。

用户确认驱动板 12 V 关闭、四轮离地、S1 松开后，已只下载至 FPGA **SRAM**，未写 Flash。Gowin Programmer 返回 `Finished`、User Code `0x4D334657`、Status Code `0x70026020`。下载后的灯与静止状态尚待用户确认。若有异味、发热、轮子持续转动或其他轮联动，立即关闭驱动板 12 V。
