# 四轮 80% PWM 离地联调

本目录只提供四个驱动电气通道的短时验收位流，不连接导航，也不启用编码器 PID。四轮同时转动不代表车会向前行驶；滚轮安装方向、电机极性和编码器正负仍须实测标定。

2026-10-19 用户确认物理轮序调整为：M1=B（左下）、M2=A（右下）、M3=C（左上）、M4=D（右上）。下表以车头朝图片上方为前提。P7 的封装球脚与物理排针位置已对照 ACG720 原理图第 11 页和厂家管脚分配表；驱动板 H1/H2 信号次序沿用此前 EDA 网表核对结果，接线前仍须看清实物 1 脚标记。

现有 `fpga_robot_core` 的轮序是 FL、FR、RL、RR；将来接闭环顶层时必须按 **FL→M3、FR→M4、RL→M1、RR→M2** 重排目标速度、对应编码器反馈及 PWM/方向输出。不能把其数组下标 0、1、2、3 直接当作 M1、M2、M3、M4。

| 驱动通道 | 物理轮 | P7 PWM / IN1 / IN2 | FPGA 球脚 | 驱动板 PWM / IN1 / IN2 |
| --- | --- | --- | --- | --- |
| M1 | B，左下 | 1 / 2 / 3 | A13 / A14 / A15 | H1-2 / H1-4 / H1-6 |
| M2 | A，右下 | 4 / 5 / 6 | A16 / A18 / A19 | H1-1 / H1-3 / H1-5 |
| M3 | C，左上 | 7 / 8 / 9 | F13 / F14 / E13 | H2-2 / H2-4 / H2-6 |
| M4 | D，右上 | 10 / 13 / 14 | E14 / C13 / B13 | H2-1 / H2-3 / H2-5 |

P7-11 是 **5 V**，P7-12 是 **GND**，P7-29 是 **3.3 V**，P7-30 是 **GND**。FPGA 和驱动板必须共地；只连接一根确认无误的 GND 到驱动板 GND，不要把驱动板 12 V、5 V 或 3.3 V 接入 FPGA GPIO，也不要带电插拔公共地线。

电机六线插头可以正常插在驱动板上，但**暂时不把驱动板 H1/H2 的 AM1/BM1…AM4/BM4 接入 FPGA**。2026-10-20 用户更正实测：AM/BM 高电平约 **5 V**，此前“约 3.3 V”无效。必须对八路编码器信号做 5 V→3.3 V 电平转换，并在 FPGA 端对公共 GND 复测后才能连接 GPIO；禁止直接接入。编码器未验证前，四轮 80% 位流完全忽略其输入，不能声称闭环。

2026-10-20 安全事件：用户确认八路 AM/BM 曾直接接入 FPGA；已确认两板断电并从 FPGA 端拔下。此时不能据四轮开环能转就断定编码器输入脚完好。后续应使用 `../encoder_probe/` 的**无电机输出**诊断方案，在电平转换与静态电压检查完成后逐轮验证输入，未通过前禁止 PID 实机试跑。

S1 单击启动四路；M1、M2、M3、M4 每隔 125 ms 错峰起动，各先 100 ms 全占空比，之后 20 kHz、80% PWM。约 0.375 秒后四路均启动，此后并行运行。第二次单击 S1 关断；S0 立即复位关断；单次启动最多 3 秒，届时自动停车。上电默认停机，并要求 S1 先松开再按。全部 IN1 在对应通道启动时为高，IN2 始终低；这只是相同**电气方向**，不是机械前进方向。LED2 心跳、LED3 就绪、LED4 运行、LED5 超时、LED6 四路使能、LED7 保留。

上板前先断开驱动板 12 V，让四轮离地，核对全部 12 根控制线的两端和公共地，无相邻脚短路；特别是 P7-10 跨过电源/地脚才接 P7-13/14。下载时选择 `SRAM Program`，文件为 `impl/pnr/acg720_motor_four_kick_80.fs`，User Code 应为 `0x46343830`。确认上电未按 S1 时 PWM/IN1/IN2 全低，按键与 LED 状态符合预期后，才给驱动板 12 V。初次联调使用可限流电源并观察电流；如果四轮错峰启动时电压明显跌落、驱动芯片过热或任一轮卡住，立即切断 12 V。车轮落地前须逐轮确认机械方向和电流，再做低速闭环。

仿真：`& 'D:\software\modelism\win64\vsim.exe' -c -do run_modelsim.do`。构建：`& 'D:\software\gowin\Gowin_V1.9.12.04_x64\IDE\bin\gw_sh.exe' build.tcl`。本工程不自动下载位流，也不会重启电脑。

2026-10-19 离线核验：ModelSim 显示 `PASS tb_acg720_motor_four_kick_80`，覆盖四路错峰、各路 80% PWM、再按停机、S0 和超时。Gowin 综合、布局布线、位流生成完成；50 MHz 时钟的建立/保持违例终点均为 0，报告最大频率约 164.092 MHz。综合提示旧 M1 控制模块内部未使用的 50% PWM 实例被移除，四个实际 80% PWM 实例仍在。本位流 SHA-256 为 `DCBD8EF37A50D04FDEB21942AD677D24F0C7D8AC54D5C307428A572273603A8E`。**四轮实机结果仍待填写**，不能用离线 PASS 代替电流、方向和编码器实测。
