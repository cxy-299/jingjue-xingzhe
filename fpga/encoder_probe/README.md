# 四路编码器安全接线验收

## 当前硬件红线

2026-10-20 用户复测驱动板 AM/BM 高电平约 **5 V**，且曾把这些线直接接入 FPGA；已确认关闭驱动板 12 V 和 FPGA 电源并从 FPGA 端拔下八根编码器线。此前“约 3.3 V”的判断作废。FPGA Bank 1 约束为 LVCMOS33、3.3 V，不能以内部下拉或修改 CST 的方式把 5 V 输入变安全。既然曾经误接，后续还要警惕输入管脚已受损或有潜在失效，不能只靠一次仿真判断硬件完好。

已到货的模块照片标有 TXS0108E、VA/VB、A1～A8/B1～B8、OE、GND。此芯片是自动双向转换器，本次仅按单方向 B→A 使用：VA 接 FPGA 的 3.3 V，VB 接驱动板的 5 V，GND 接两板公共地。VA 不得大于 VB；OE 由 3.3 V 侧控制，建议下拉为禁用态，待两侧供电稳定后再拉高，不能悬空。TXS0108E 对长线和较大容性负载较敏感，线缆尽量短；若出现误计数，先用示波器查 A/B 端毛刺，再考虑改用固定方向缓冲器，不能靠调 PID 掩盖。

禁止把驱动板 5 V 直接接到任意 FPGA GPIO，也不能把两个板子的 5 V/3.3 V 电源输出直接互连。接 FPGA 前，用万用表和示波器分别确认每路转换器输出低电平、高电平、切换过程都在 FPGA 容许范围内，并确认掉电状态不会反灌电。连接与断开均须两板断电。诊断工程的八个 FPGA 输入已配置为 `PULL_MODE=NONE`，避免内部下拉削弱 TXS0108E 的高电平。

## 功能与引脚

本位流是**编码器输入诊断版，不是 PID 位流**。12 根电机驱动输出 PWM/IN1/IN2 都被绑为常低，故不会使电机主动转动。手动转动离地车轮时，LED4、LED5、LED6、LED7 分别代表 M1、M2、M3、M4 的编码器活动；最近一次计数为正时持续亮，为负时约 5 Hz 闪烁，停止转动约 0.5 s 后熄灭。LED2 为心跳，LED3 为复位释放/就绪。S0 按下会清零计数与活动灯。LED 的正负只代表 A/B 相位顺序，不代表物理前进方向。

| 电机 | 物理轮 | 驱动板信号 | FPGA 排针（仅接转换后的 3.3 V 信号） | FPGA 球脚 |
| --- | --- | --- | --- | --- |
| M1 | B，左后 | AM1 / BM1 | P7-15 / P7-16 | D14 / D15 |
| M2 | A，右后 | AM2 / BM2 | P7-17 / P7-18 | C14 / C15 |
| M3 | C，左前 | AM3 / BM3 | P7-19 / P7-20 | B15 / B16 |
| M4 | D，右前 | AM4 / BM4 | P7-21 / P7-22 | D17 / C17 |

| 驱动板编码器线 | 转换器 5 V 侧 | 转换器 3.3 V 侧 | FPGA P7 |
| --- | --- | --- | --- |
| AM1 / BM1 | B1 / B2 | A1 / A2 | 15 / 16 |
| AM2 / BM2 | B3 / B4 | A3 / A4 | 17 / 18 |
| AM3 / BM3 | B5 / B6 | A5 / A6 | 19 / 20 |
| AM4 / BM4 | B7 / B8 | A7 / A8 | 21 / 22 |

物理轮序由用户确认；P7 位置和封装球脚沿用 ACG720 管脚表核对结果，但上板前仍须在**断电**状态下逐针复核实物排针定位和连接连续性。当前没有编码器每圈计数、减速比、轮径与前进时的 A/B 相序数据，因此**不得把本诊断版计数直接当作速度闭环标定结果**。

## 2026-10-22 上板手转验收

- 四轮离地、12 V 初始关闭，SRAM 下载显示 `Finished`，User Code `0x454E4331`、Status Code `0x70026020`。LED2 闪烁、LED3 常亮、LED4～7 初始全灭。
- 开启驱动板 12 V 后没有电机意外转动、异味或明显发热。依次手转 M1～M4，只有对应的 LED4～7 响应；停止约半秒后熄灭，未观察到通道串扰。
- 按“轮子下缘朝车尾移动”的统一方向手转，M1/M2/M3/M4 的灯型依次为闪烁/常亮/闪烁/常亮；按本诊断逻辑分别对应负/正/负/正计数。这是**手转方向极性**，尚未确认电机驱动极性及每圈计数。
- 这组现象证明四路低速输入链路在当前连接下均有响应；不能据此宣称高速计数准确、电平转换边沿无毛刺或闭环 PID 已通过。

## 电平转换完成后的验收顺序

1. 两板保持断电，逐一核对八路 AM/BM 的转换器输入和输出，确认共地及转换器供电/方向设置；不要利用 P7-11 的 5 V 作为 GPIO 信号。
2. 只给转换器及编码器侧供电、FPGA 端保持断开，测八路 FPGA 侧输出的高/低电平和是否存在超过 3.3 V 的尖峰；确认先后掉电不会反灌。
3. 断电后接 FPGA，暂不接驱动板 12 V 电机功率电源；只在必要的安全供电下下载本诊断位流并确认 LED2 心跳、LED3 就绪、LED4～7 初始全灭。若编码器必须由驱动板 12 V 供电，必须保持全部 PWM/IN1/IN2 常低并让四轮离地，限流供电。
4. 分别手动转动 M1～M4，观察只有对应 LED 有活动，记录正/反转灯型和每轮是否存在不计数、常亮、串扰。发现异常立即断电排查，尤其先前直接误接的输入脚。
5. 独立测定每轮每圈的四倍频计数和“车辆前进”为正/负；之后才确定闭环采样周期、目标计数与 PID 参数，并从单轮低速开始调试。正式闭环须另行仿真和编译。
