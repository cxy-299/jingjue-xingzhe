# 蓝牙手动驾驶与在线 PID 调参预留方案

当前状态：**仅完成接口/安全设计，未接蓝牙模块、未实现协议解析，也不能用手机操控电机。**不要把蓝牙串口直接并到树莓派视觉 UART 上；选择单独的 3.3 V TTL UART RX/TX 和独立接地。蓝牙模块型号、实际输出电平和 ACG720 引脚须根据实物核实。

## 控制权与安全优先级

1. 物理急停、ToF 失效/近距硬停车、电机驱动故障总是最高优先级，任何模式都不能覆盖。
2. 上电默认停车；`AUTO` 才允许 FPGA 自主导航策略输出；`MANUAL` 只能让 FPGA 接收手机给出的 `vx/vy/omega` 速度意图，仍由 FPGA 完成麦轮混控、编码器闭环和 PWM。
3. 手机切换模式时先清零速度与四轮 PID 历史量，并等待一个控制周期重新使能；禁止从自动模式的旧速度直接切到手动模式。
4. 蓝牙手动指令需有独立的短看门狗（建议 300 ms）；超时即停车。它不依赖树莓派视觉心跳。自动模式的视觉/导航超时另行管理。
5. 比赛自主导航展示时保持 `AUTO`，手机只用于调试/急停，不以手机遥控代替赛题的 FPGA 自主导航。

## 预留的数据边界

建议未来增加 `bt_uart_rx`、`bt_packet_parser`、`control_mode_arbiter` 三层。解析器输出经过 CRC 校验的结构化命令，不直接写 PWM 或方向管脚：

| 命令 | 建议字段 | 处理要求 |
| --- | --- | --- |
| 模式 | STOP / AUTO / MANUAL | 切换先停车，再确认模式；失联默认 STOP |
| 手动速度 | `vx, vy, omega`，有符号千分比 | 分量限制在安全范围内；仅 MANUAL 且指令新鲜时采纳 |
| 急停 | 置位/复位请求 | 软件只能追加停车；解除必须人工确认，不覆盖物理急停 |
| PID 设置 | 轮号、`Kp/Ki/Kd/shift`、序号 | 只在停车且电机失能时提交；设上下界并回显生效值 |
| 状态查询 | 模式、四轮目标/测速/占空比、故障位 | 发送给手机用于调参，不反向控制 |

协议建议采用固定帧头、版本、长度、序号、命令号、负载、CRC16；错误长度/CRC/重放序号一律丢弃。手机端不要发送摄像头图像给 FPGA，发送的是低带宽控制意图；视觉目标数据仍走现有树莓派串口协议。

`wheel_pi.v` 目前 `KP/KI/KD/SHIFT` 是**综合期参数**，手机不能直接调它们。实现在线调参时应新增有界运行时寄存器，停车时原子更新四轮参数；更新时清除积分和微分历史，并用仿真覆盖饱和、负值、通信中断、模式切换。实车首次调参应架空车轮、设置低占空比上限，确认编码器方向与电机方向后再逐步放开。
