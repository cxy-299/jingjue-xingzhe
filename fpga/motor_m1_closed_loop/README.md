# M1 离地 PI 闭环标定（M1CL）

本位流只驱动 M1（左后/B）；M2、M3、M4 的 PWM/IN1/IN2 全部恒低。**当前只允许四轮离地试验，不是可落地的四轮闭环位流。**车轮方向、负载参数与其他三路的带电反馈尚未完成验证。

## 已知硬件实测输入

- EMR3 串口在 80% 空载下收到 `M1:-026`、`M1:-027`、`M1:-027`，单位是编码器四倍频计数/10 ms。M1 前进时原始符号为负，因此本控制器将反馈反号。
- 编码器经过 TXS0108E 5 V→3.3 V 转换，A/B 接 FPGA D14/D15；驱动板与 FPGA 已共地。若电平转换器失电、松线或更换接线，不得直接运行。

## 本版控制与保护

- S1 单击启动或手动停止；S0 低电平异步切断 PWM 与 IN1。下载、复位后需先稳定松开 S1 才能启动。
- 20 kHz PWM；起动 100 ms 为 100%，其后目标为 20 计数/10 ms。基准占空比 600‰，比例增益 8‰/计数，积分增益 1‰/(计数·采样)，积分限幅 ±200‰，运行占空比限制 300～850‰。这些是**离地初始参数**，不能视为负载整定值。
- 单次运行 2 秒硬超时。起动窗口后连续约 200 ms 无有效前进编码器反馈、连续三次检测到反向反馈，或单周期超过 50 计数，则故障锁存并关断。故障仅通过 S0 复位清除。
- LED2 心跳、LED3 就绪、LED4 当前运行、LED5 两秒超时、LED6 曾收到有效前进反馈、LED7 故障。LED6 是本次复位后的历史指示，停车后可能仍亮。
- FPGA 板载串口 115200 8N1，每约 100 ms 发送一行 `M1 T020 A+026 D0600 F0`。T=目标、A=本次速度、D=当前 PWM 千分比、F=故障；若 A 为负，说明物理方向与预期不符。串口仅遥测，不接收驾驶命令。

## 上板检查表（不得跳步）

1. 用户确认驱动板 12 V 关闭、四轮离地。已于 2026-10-23 只向 FPGA SRAM 下载本目录位流，不写 Flash；Gowin Programmer CLI 返回 `Finished`、User Code `0x4D31434C`、Status Code `0x70026020`。下载后仍保持 12 V 关闭，待用户确认 LED2 闪、LED3 亮、LED4～7 灭、四轮静止。
2. 电脑 XCOM 连接板载 CH340 串口 COM6，115200 8N1；打开驱动板 12 V，S1 未按时四轮仍应静止。任何异味、发热、异常转动立即关 12 V。
3. 单击 S1，仅 M1 转动不超过 2 秒；记录是否前进、LED 状态以及至少 10 行 `M1 ...` 遥测。目标与实际计数不应被误当 RPM。若 LED7 亮或 `A` 持续为负，立即停机排查编码器/方向。
4. 在安全前提下重复一次并轻微阻尼 M1 轮缘，观察实际速度降低时 D 是否上升、恢复时 D 是否回落；不能用手堵转或接触高速轮。完成后关闭 12 V。
5. 只有依次完成 M2～M4 的方向、极性、限时闭环和带载保护，再在四轮离地状态做四路闭环，才进入低速短距离下地测试；届时必须添加物理急停、车体防跌落和限速。

### 首次离地闭环试转（用户现场反馈）

用户确认：12 V 接通、S1 未按时四轮静止且无异常；单击 S1 后仅 M1 转动并在约 2 秒内自动停止。电脑串口收到 `M1 T020 A+000 D0000 F0`、起动 `A+002 D1000`、最高观察到 `A+031 D0600`，随后 `A+026 D0462`、`A+021 D0470`、`A+016 D0517`、`A+013 D0602`、`A+014 D0673`、`A+016 D0710`、`A+019 D0723`、`A+019 D0711`、`A+020 D0715`。这些数据表明控制器确实依据编码器速度调整 PWM，并在记录末尾接近 20 计数/10 ms；所有所示帧故障位均为 `F0`。这**仅证明离地 M1 闭环趋势**，尚未验证带载扰动、M2～M4 或地面行驶；停机后 LED 状态尚待逐项确认。
