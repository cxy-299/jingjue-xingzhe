# M2～M4 逐轮方向与编码器标定（M3CA）

本位流**只用于四轮离地**的短时电气标定，不是闭环位流，也不可让小车落地。起始选中 M2（原 A，右后），之后每次 S1 试转结束依次选中 M3（原 C，左前）、M4（原 D，右前），再回到 M2。每轮启动 100 ms 为 100% 占空比，此后 80% PWM；单次最长 700 ms。任一时刻仅一轮的 PWM/IN1 使能，其余轮保持低电平。S0 急停并重置轮号为 M2。

## 串口与保护

- 电脑板载 USB 串口：115200、8N1，ASCII 输出 `M2:+027`、`M3:-025` 这类报文。符号是**编码器原始相序**，不代表机械前进方向；须同时目视记录轮子下缘朝车头或车尾运动。
- 起动窗口后若约 200 ms 没有有效计数，或计数超过 80/10 ms，故障锁存、PWM 停止；需 S0 复位，不可连按 S1 绕过故障。
- LED2 心跳、LED3 就绪、LED4 当前运行、LED5 700 ms 超时、LED6 曾有有效反馈、LED7 故障。LED6 在停机后仍可能亮。
- 如电机未按 700 ms 自动停、出现异味/过热/异常电流，应立即关闭驱动板 12 V，勿继续下一轮。

完成三轮标定后，才可将每轮原始编码器符号修正为车体前进正速度，复制 M1 PI 控制到四通道，再做四轮离地闭环与低速落地测试。

**方向注意：**最初口述三轮均“朝车头”，但用户随后明确更正为“M2远离车头，M3靠近，M4远离”，并进一步确认这指车轮接地处（最下缘）：M2/M4 朝车尾、M3 朝车头。因此四轮前进控制应**仅反置 M3** 的方向。M3 在同样 80% PWM 下空载计数仅约 10～12，明显低于 M1/M2/M4，需排查机械阻力、接线与编码器每转计数，不能直接套用同一 PI 基准占空比。
