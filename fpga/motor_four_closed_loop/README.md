# 四轮闭环离地试验（4CL2）

此工程是四轮同时工作的**限时诊断位流**，不是小车落地运行或比赛最终导航位流。电机驱动板 12 V 接通后，S1 单击启动/再次单击停止，S0 立即断开四路控制信号。一次运行最长 2 秒；任一路编码器失联、持续反向计数或超速时锁存故障，四轮全部停下，必须按 S0 才能清除。

## 已确认的通道与方向

| 逻辑通道 | 实物位置 | 前进 IN1/IN2 | 前进原始计数 | 控制用速度 |
|---|---|---|---|---|
| M1 | 左前，原 B | 0/1 | 预计正，待 4CL2 上板复核 | 原始值不变 |
| M2 | 右前，原 A | 1/0 | 负 | 原始值取反 |
| M3 | 左后，原 C | 0/1 | 正 | 原始值不变 |
| M4 | 右后，原 D | 1/0 | 负 | 原始值取反 |

**实物车头已由用户确认为 M1/M2 端。**上表左右方位沿用照片中 M1/M3 在左、M2/M4 在右的观察方向；实际安装时仍应在车身贴箭头核对。4CL2 仅翻转 M1 驱动方向与反馈归一化极性，其他三轮不变。M1 修正后的机械方向和原始计数尚待实测，不可把仿真结果当作通过。

四路编码器已经通过 TXS0108E 由 5 V 转为 3.3 V 后进入 FPGA；不得把驱动板 AM/BM 直接接 FPGA。FPGA、驱动板和电平转换器必须共地。

## 控制与安全边界

- FPGA 时钟 50 MHz；PWM 20 kHz；速度采样每 10 ms 一次，目标 20 个四倍频计数/10 ms。
- M1、M2、M3、M4 相隔 125 ms 起动，避免四路 100% 起动脉冲同时出现。每路起动脉冲 100 ms，随后 PI 控制；占空比 300～850‰。错峰设计只用于离地联调，未做底盘落地起步验证。
- PI 参数沿用已实测的 M1 单轮闭环：基准 600‰，KP=8，KI=1，积分限幅 ±200。参数能在离地时稳定，不代表载重落地后已完成整车调参。
- 任一路连续约 200 ms 无有效反馈、连续 3 个采样周期明显反向、或单采样超过 50 计数，故障锁存并停四轮。
- 该位流没有惯导、地图避障、目标跟踪或自主行驶逻辑；串口只发送诊断帧，不接收运动命令。

## 串口与 LED

电脑连接板载 CH340 串口，115200、8N1。每 100 ms 轮询一轮，示例：`M2 T020 A+028 D0600 F0`。`T` 是目标计数，`A` 是归一化后有符号实际计数，`D` 是千分比占空比，`F1` 表示故障。四轮完整一轮数据约 400 ms；运行仅 2 秒，建议复制连续输出而不是只看单行。

LED2 心跳；LED3 就绪；LED4 任一路输出使能；LED5 到达 2 秒硬超时；LED6 四路都曾收到有效反馈；LED7 任一路故障。LED6 在停止后可保持亮到下一次 S0 复位，表示本次复位以来四路均有反馈，并非仍在转动。

## 2026-10-23 验证记录

- 4CL1 初版 ModelSim：PASS，编译错误 0、警告 0；Gowin 实际 Fmax 77.918 MHz、建立/保持违例均 0，逻辑 4028/59904、寄存器 841/60780。SRAM 下载 User Code `0x34434C31`、`Finished`，未写 Flash；初版 SHA-256 为 `39822001947581C8A3722FB77A662A8FB100471FEF13CEFAA7623CC61124AD68`。
- 4CL2 修正版 ModelSim `vsim -c -do run_modelsim.do`：PASS，编译错误 0、警告 0；覆盖修正后 M1/M3 方向、125 ms 错峰、四路 PI 响应、UART 完整字段、2 秒硬超时、S0 异步急停、M3 编码器失联全停、M2 编码器反向全停。
- 4CL2 Gowin V1.9.12.04 综合布线：GW5AT-LV60PG484AC1/I0，50 MHz 约束，实际 Fmax 72.838 MHz，建立/保持违例均 0。综合器提示未使用的按键模块内部 PWM 被优化，符合复用其按键逻辑的设计意图。4CL2 User Code `0x34434C32`，位流 SHA-256：`26770213C5B9A386177E814B9C9AD2080D3DC4F0552BFB4B00F751F80E2A3985`。
- 下载后 12 V 关闭的初态、12 V 接通但未按 S1 时的静止状态，用户均已确认正常。
- 4CL1 四轮离地闭环试转：用户报告 M1 与其余三轮的机械转向相反。尽管四路串口速度均收敛至约 `A+020`、`F0`，**初版整车前进方向验收未通过**；不得落地。随后用户明确车头在 M1/M2 端，4CL2 已按此修正 M1，待上板复核。
- 运行中的一组实测数据：M1 `T020 A+020 D0688 F0`、M2 `T020 A+020 D0712 F0`、M3 `T020 A+020 D0707 F0`、M4 `T020 A+020 D0708 F0`。最初为 `A+000 D0000`，说明采到了起动前的轮询帧；后续有 `M3 A+017 D0000 F0`，`D0000` 表示那一帧采样时通道已关闭，不能据此判断运行中速度不稳。
- 4CL2 修正后离地复测：用户确认四轮最下缘运动方向相同，且全部约 2 秒自动停下。连续轮询中四轮收敛到 `M1 A+020 D0700 F0`、`M2 A+020 D0712 F0`、`M3 A+020 D0706 F0`、`M4 A+021 D0711 F0`；停机后 LED5/LED6 亮、LED7 灭。此前串口中的 `D1000` 是错峰起动脉冲，不是持续 PI 输出。**4CL2 离地方向与限时闭环验收通过，但尚未落地验证。**
- 落地运动：**未验证，暂不执行**。
