# M1 编码器计数标定（EMR1）

此位流**不是 PID 闭环**。只让 M1（B 轮、左后）按已实测的方向短时开环试转 700 ms，记录去掉前 200 ms 起动段后的四倍频编码器计数，用 FPGA 板载 LED 显示量级。M2～M4 的全部 PWM/IN1/IN2 输出恒低。

## LED 读数

- 启动前：LED2 心跳闪烁、LED3 就绪常亮，其余全灭。
- 单击 S1 后：只允许 M1 运行，先 100 ms 全占空比起动，再 80% PWM；约 700 ms 自动停止。S0 可立即停车。
- 自动停止后：LED2～LED7 变为**六位静态二进制读数**，LED2 权重 1、LED3 权重 2、LED4 权重 4、LED5 权重 8、LED6 权重 16、LED7 权重 32；亮的权重相加得到显示码 `C`。这时 LED2 **不再闪烁**是正常的，不能用旧版 LED5/6/7 含义解释。
- 采样窗口为起动后 200～700 ms，共 500 ms。显示码 `C = floor(|位置(700 ms)-位置(200 ms)| / 100)`，所以该窗口的平均速度约为 `2C～2(C+1)` 个**四倍频计数/10 ms**。例如仅 LED2、LED4、LED6 亮，`C=1+4+16=21`，平均约 42～44 计数/10 ms。
- `C=63` 为饱和，意味着至少约 126 计数/10 ms，不能当成精确读数；`C=0` 只表示低于约 2 计数/10 ms，也需排除编码器断线。此法读**幅值**，M1 的负极性已由 EMD1 独立确认。

## 安全与限制

四轮必须离地，驱动板 12 V 关闭时才下载 SRAM 位流，下载后先检查初态。若上电后未按 S1 便有电机转动，或除 M1 外任何轮转动，立即关闭 12 V。探头和编码器线必须经 TXS0108E 电平转换；禁止将约 5 V 的 AM/BM 直接接 FPGA。试转结束后先记录 LED2～7，再关闭 12 V。

标定值仅反映离地、80% PWM、该电源电压下的短时平均速度；不代表带载速度，不足以证明闭环稳定。下一阶段须把 M1 前进方向的**负**计数转换成车体正向反馈，先做单轮限时闭环仿真，再上板测试，最后逐轮标定。
